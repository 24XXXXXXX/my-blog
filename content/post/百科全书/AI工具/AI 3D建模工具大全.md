## 七、常见问题

### Q1：这些工具生成的模型质量如何？

**A**：
- **低模（Low Poly）**：适合游戏、VR/AR，多数工具都支持
- **高模（High Poly）**：适合渲染、3D 打印，推荐 Rodin、Kaedim
- **拓扑质量**：Rodin、CSM 口碑较好

### Q2：生成的模型可以商用吗？

**A**：
- **腾讯混元3D**：开源版可商用，在线版需查看服务条款
- **Tripo/Meshy/Rodin**：付费版通常可商用，免费版需查看许可
- **Kaedim**：商业授权明确

**建议**：使用前查看各工具的 Terms of Service

### Q3：如何选择适合自己的工具？

**决策树**：
```
是否需要中文？
├─ 是 → 腾讯混元3D / Tripo / Rodin
└─ 否 → Meshy / Spline / CSM

是否有预算？
├─ 无 → 腾讯混元3D / Meshy Free / Tripo Basic
└─ 有 → Rodin / Kaedim

主要用途？
├─ 游戏开发 → Tripo / CSM / Sloyd
├─ 网页展示 → Spline
├─ 3D 打印 → Tripo / Meshy
└─ 商业项目 → Rodin / Kaedim
```

### Q4：这些工具会替代 3D 建模师吗？

**A**：不会。这些工具适合：
- 快速原型
- 概念验证
- 低成本资产生成

**仍需 3D 建模师**：
- 复杂场景搭建
- 精细调整
- 动画绑定
- 特殊效果
